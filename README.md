# Superstore Sales Dashboard

This project analyzes Superstore sales data using Python and Excel.

## Tools Used
- Python
- Pandas
- Excel
- Pivot Tables
- Pivot Charts

## Project Workflow
1. Data cleaning using Pandas
2. Data analysis using Python
3. Export cleaned dataset to Excel
4. Dashboard creation using Pivot Tables and Charts

## Key KPIs
- Total Sales
- Total Profit
- Total Orders

## Key Insights
- Technology category generated highest sales and profit
- Furniture category had low profitability
- West region generated highest sales
- Sales peaked during November and December

## Dashboard Features
- Monthly Sales Trend
- Category-wise Sales
- Category-wise Profit
- Regional Sales Analysis
- Top Products Analysis
